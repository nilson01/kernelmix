# Citation and license

[Bobb et al. (2015)](https://doi.org/10.1093/biostatistics/kxu058) introduced Bayesian kernel machine regression for exposure mixtures. [Bobb et al. (2018)](https://doi.org/10.1186/s12940-018-0413-y) described the R software and its binary-outcome extension. Cite these method sources separately from KernelMix, which is a Python implementation with additional model options.

KernelMix's software citation is recorded in [CITATION.cff](https://github.com/nilson01/kernelmix/blob/main/CITATION.cff). The package uses the [GPL-2.0-only license](https://github.com/nilson01/kernelmix/blob/main/LICENSE), with source attribution in [NOTICE](https://github.com/nilson01/kernelmix/blob/main/NOTICE). These files accompany the source distribution.
